# Changelog

## v0.1.1

- Rebranded the project as `HA Supertronics HAT UPS X120x`
- Added local brand assets for Home Assistant
- Improved compatibility with older config entries
- Added configurable AC power inversion and raw GPIO diagnostics
- Fixed GPIO value handling across `gpiod` versions
- Added HACS validation and Hassfest workflows

## v0.1.0

- Initial public HACS-ready release
- Battery percentage, voltage and state sensors
- AC power binary sensor
- Manual and automatic charging controls
- Configurable stop/resume charging thresholds
- Config flow, options flow and basic unit tests
